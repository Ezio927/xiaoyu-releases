# 小鱼 · v2.1.1 朋友试用版

Windows 64位、本机运行的桌面陪伴软件。软件免费，聊天使用你自己的 DeepSeek 官方 API，调用费用由你自行承担。

## 下载与安装

下载 [小鱼 v2.1.1 安装器 ZIP](https://github.com/Ezio927/xiaoyu-releases/releases/download/v2.1.1/Xiaoyu-Setup-2.1.1-win-x64.zip)，完整解压后双击“小鱼安装器.exe”。

已安装 v2.0.2 的用户可在小鱼的设置中检查程序更新。也可以从托盘彻底退出小鱼，等至少 5 秒，再运行新版安装器。升级沿用原有个人资料目录。

安装器约147 MiB，自带运行环境，不需要另装 Node 或 Python。它会下载并校验约7 GB程序；建议至少预留24 GB下载和安装空间。语音组件按需独立下载。不要手动拼接 `bundle-*.bin`，也不要在安装器里填写密钥或账号。

[本版说明与已知限制](https://github.com/Ezio927/xiaoyu-releases/releases/tag/v2.1.1)

v2.1.1 更新了主界面和桌宠侧边按钮。独立桌宠支持自由走动、提起和落地，也支持双击左 Alt 原地听写。识别文字进入草稿，确认后发送。

在「屏幕陪伴 → 指定应用窗口」选择目标后，可分别授权观察和操作。小鱼可查看全窗或局部，并按你的要求点击、滚动和填写 Windows 标准控件。窗口权限在暂停、换窗口、锁屏或重启后撤销。

## 使用与资料

安装后填写自己的 API。QQ/Oopz 按需连接，不启用也能使用桌面聊天、共同记忆和日记。

默认个人资料位于 `%APPDATA%\XiaoyuCompanion\personal`，与程序目录分开。升级保留人设、聊天、记忆、日记、设置、背景图片和当前音色；升级前建议另外保留备份。大型语音组件及音色权重需另行保留或重新准备。

关闭主窗口会收起到托盘，选择“彻底退出”才会停止后台。退出后稍候再重开，不要同时运行两套收发同一QQ/Oopz账号的实例。
