# 小鱼 · v2.0.2 朋友试用版

Windows 64位、本机运行的桌面陪伴软件。软件免费，聊天使用你自己的 DeepSeek 官方 API，调用费用由你自行承担。

## 下载与安装

当前公开安装器与签名清单已验证，空缓存完整下载和安装正在最后复验；应用内更新入口尚未开放。复验结果会更新到本页。

下载 [小鱼 v2.0.2 安装器 ZIP](https://github.com/Ezio927/xiaoyu-releases/releases/download/v2.0.2/Xiaoyu-Setup-2.0.2-win-x64.zip)，完整解压后双击“小鱼安装器.exe”。

安装器约147 MiB，自带运行环境，不需要另装 Node 或 Python。它会下载并校验约7 GB程序；建议至少预留24 GB下载和安装空间。语音组件按需独立下载。不要手动拼接 `bundle-*.bin`，也不要在安装器里填写密钥或账号。

[本版说明与已知限制](https://github.com/Ezio927/xiaoyu-releases/releases/tag/v2.0.2)

v2.0.2 修复了安装还原资源文件失败的问题，并包含安装与更新下载采用 Windows 系统代理的修复。无需修改系统代理设置；下载仍逐步校验跳转、签名及文件内容。网络中断可重试，不保证所有网络环境都能连接。该修复不代表 DeepSeek API 的连接超时也一并解决。

## 使用与资料

安装后填写自己的 API。QQ/Oopz 按需连接，不启用也能使用桌面聊天、共同记忆和日记。

默认个人资料位于 `%APPDATA%\XiaoyuCompanion\personal`，与程序目录分开。升级保留人设、聊天、记忆、日记、设置、背景图片和当前音色；升级前建议另外保留备份。大型语音组件及音色权重需另行保留或重新准备。

关闭主窗口会收起到托盘，选择“彻底退出”才会停止后台。退出后稍候再重开，不要同时运行两套收发同一QQ/Oopz账号的实例。
